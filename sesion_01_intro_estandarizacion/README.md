# 🟩 Sesión 1 – Introducción y Estandarización de Proyectos

**Duración:** 4.5 horas (7:30 a.m. – 12:00 m)  
**Objetivo:** establecer la estructura base de los proyectos y unificar criterios de programación entre los participantes.  

---

## 🧭 Contenido

### Parte A – Grupo 1 y 2 (PLC #1)
- Configuración del proyecto base en **EcoStruxure Control Expert**.  
- Selección de CPU **BMEP581020** y módulos de E/S.  
- Configuración de comunicación Ethernet local.  
- Verificación de conexión PLC ↔ PC.  

### Parte B – Grupo 3 y 4 (PLC #2)
- Replicación del proyecto con estructura estandarizada.  
- Documentación inicial de variables y bloques creados.  
- Subida del proyecto al **repositorio GitHub** del curso.  

---

## 📘 Recursos
- Archivo base: `plantilla_proyecto_base.zrx`  
- Manual de referencia rápida: [handout_resumen.pdf](../../materiales/handout_resumen.pdf)  
- Carpeta `/recursos/` de esta sesión.

## 🧩 Reto 1 – Proyecto Base Documentado
**Meta:** tener el primer proyecto base funcional, documentado y sincronizado entre ambos PLCs.

**Entregables:**
- Proyecto `.zrx` con CPU configurada y comunicación validada.  
- Lista de variables iniciales exportada en `.csv`.  
- Captura de conexión y comunicación estable.  
- Carpeta `Sesion_01` actualizada en el repositorio.

**Validación del instructor:**
- Proyecto compila y descarga sin errores.  
- Documentación cumple formato estándar.  
- GitHub actualizado por ambos grupos.
