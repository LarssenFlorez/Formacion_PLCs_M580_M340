# 🧠 Formación Técnica en PLC Schneider M580 / M340  
### Curso Avanzado – Programación y Protocolos Industriales  

Este repositorio contiene todo el material oficial del curso práctico de formación avanzada en controladores **Schneider M580/M340**, impartido por **ENCERT S.A.S.**  

El curso está orientado a **ingenieros con experiencia en IEC 61131-3** que buscan dominar la integración de protocolos industriales, diseño estructurado de librerías y estrategias de migración desde plataformas como **ControlWave** hacia el ecosistema **EcoStruxure Control Expert**.

---

## 🎯 Objetivos del curso
- Aplicar buenas prácticas de programación estructurada bajo IEC 61131-3.  
- Crear librerías reutilizables (DFB/FB) y plantillas de proyecto estándar.  
- Integrar comunicación **Modbus, Profinet, Profibus y DNP3**.  
- Ejecutar pruebas con hardware real (2 PLC M580).  
- Desarrollar un **proyecto integrador completo** basado en una estación crítica.  
- Preparar un **plan de soporte y migración masiva** hacia PLC Schneider.  

---

## 🧩 Metodología
- **100% práctica:** aprender haciendo.  
- **Rotación de equipos:** dos PLC M580, cuatro ingenieros trabajando en pares.  
- **Reto por sesión:** cada módulo incluye un entregable funcional.  
- **Repositorio GitHub:** centraliza avances, códigos, documentación y bitácoras.  

---

Cada sesión incluye:
- `README.md`: guía principal  
- `/recursos/`: archivos de soporte (zrx, csv, diagramas)  
- `/ejercicios/`: instrucciones y retos prácticos  

---

## 📘 Requisitos
- **EcoStruxure Control Expert V15 o superior**  
- 2 PLC M580 con módulos de comunicación  
- 4 laptops (Minimo Core i5, 16 GB RAM o más)  
- Switch local (Ethernet TCP/IP)  
- Acceso a red local / Wi-Fi visitantes (para GitHub y diagnósticos)
